# ZCode handoff: college website chatbot

Open this folder in ZCode and use the updated spec at `.scratch/college-website-chat/spec.md` as the source of truth. Codex completed `/to-tickets` with the user's approval and published tickets under `.scratch/college-website-chat/issues/`. Ticket 01 has been re-implemented in Next.js App Router with persistent local SQLite and is marked `ready-for-human`; review its recorded evidence, then build ticket 02 with invite-only named staff login, required multifactor authentication, and the first shared inbox. Supabase Postgres migration is ticket 11 and a gate before deploying on Vercel.

Read `AGENTS.md`, `GLOSSARY.md`, `docs/agents/issue-tracker.md`, and `docs/agents/triage-labels.md` before implementing. The latest spec makes a site-wide WordPress script the default integration; a custom loader plugin is optional. Do not infer the earlier plugin proposal from the conversation.

Suggested skills in `.zcode/skills/`: `/implement` for each ready ticket, with `/tdd` at the agreed API flow seam and `/code-review` before committing. `/ask-matt` can route a change in direction. Repository setup has already been completed; do not rerun it.

This workspace contains the Next.js visitor API, SQLite store, deterministic matcher, WordPress widget loader, and cross-origin chat iframe from ticket 01. The visitor credential stays in chatbot-origin session storage and expires server-side. Ticket 02 adds the protected staff dashboard; tickets 04, 05, 08, 09, and 10 expand it with replies, answer management, staff management, hours, and retention. The college WordPress site is a separate project: this repository supplies the embed script and a test fixture, with production embedding after the hosted chatbot passes the launch gate. Public chat API endpoints remain callable from the browser, while privileged keys and staff authorization stay server-side. A Git repository is initialized on `main` and connected to `https://github.com/JustMe1234567/sfc-chatbot.git`. College IT or site owner approval of external hosting, messaging, and email services is a production launch gate documented in the spec.
