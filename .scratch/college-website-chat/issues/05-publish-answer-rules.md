# 05: Publish answer rules and topic buttons

**What to build:** Authorized staff can maintain approved answers in the chatbot dashboard. Publishing a rule makes its topic button, response, aliases, and optional college page link available to visitors without redeploying the widget.

**Blocked by:** 02: Unknown question reaches the shared inbox.

**Status:** ready-for-agent

- [ ] Authorized content editors can create, revise, preview, publish, and unpublish an answer rule.
- [ ] Published rules can include a topic button, approved response, phrase aliases or keyword conditions, and an optional college page link.
- [ ] Draft and unpublished rules never answer visitors; publishing or unpublishing changes the visitor experience without a widget redeploy.
- [ ] The dashboard shows who published a rule and when its answer was last reviewed.
- [ ] A complete flow proves that an editor publishes a rule and a visitor receives it, while an unauthorized user cannot publish one.
