## Current behavior

- the visitor name in each row (the `.contactsRowLink` that stretches over the row).

The cause is confirmed in `src/app/dashboard/dashboard.module.css`: the ticket-74 `.contactsSort` and `.contactsRowLink` rules never set `text-decoration`, so the `<a>` default shows through. Remove the underline from the contacts table's links: `text-decoration: none` on `.contactsSort` and `.contactsRowLink` (hover included), matching the dashboard's existing link conventions.

Nothing else about the table changes. The links' remaining interactive affordances stay exactly as they are, so the controls remain recognizable as interactive without the underline:

- sort headers keep their uppercase bold styling, chevron/sort icons, active-sort color, and `:focus-visible` outline;
- the row link keeps its bold weight, the row hover background, and the stretched click/focus target;
- the phone-width stacked cards use the same classes, so the name-link underline disappears there too — no separate mobile change.

The fix is class-level on the two existing rules. No global reset, no new rule elsewhere, no change to any other page's links.
