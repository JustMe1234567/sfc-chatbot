# 70: Add configurable chatbot and dashboard branding settings

**Status:** ready-for-human  
**Category:** enhancement  
**Priority:** P2  
**Related:** [16: Springfield College branding](16-springfield-college-branding.md), [40: Square icon-only launcher](40-square-icon-only-launcher.md), [46: Reference-led fresh chat](46-reference-led-fresh-chat-layout.md), [52: Sidebar navigation](52-collapsible-sidebar-navigation.md), [57: Individual sidebar hover labels](57-icon-sidebar-with-individual-hover-labels.md)

## Current behavior

The chatbot launcher, widget identity, bot avatars, and dashboard crest use fixed files from the deployed application. The launcher is fixed at a 56 px outer size with a 40 px image, 8 px padding, and a white background. The admin dashboard has no dedicated Settings destination and no interface for changing its browser-tab favicon. Changing these assets requires editing and redeploying the project.

## Desired behavior

Add a gear-icon **Settings** destination to the existing dashboard sidebar. It is available to owner, staff, and editor roles and follows the sidebar's existing collapsed, expanded, mobile, active, hover-label, focus, and sticky-layout behavior.

The Settings page provides two independent branding controls:

1. **Chatbot icon** — used consistently on the launcher/chathead, widget identity/header, greeting, and bot avatar wherever the chatbot icon appears.
2. **Dashboard favicon** — used only as the browser-tab icon for dashboard authentication and admin pages. It does not replace the existing SFC crest in the sidebar and does not affect the public demo or embedded widget page favicon.

Each control supports image upload, preview, Save, and an independent Reset to the bundled Springfield College default. Accept PNG, JPEG, and WebP files up to 500 KB. Validate the actual uploaded content on the server, reject malformed/oversized files and unsupported formats such as SVG, and never rely only on the browser-supplied filename or MIME type.

Add chathead appearance controls alongside the chatbot icon:

- Background color picker plus editable hex value, defaulting to **#013C78**.
- Bounded slider/numeric controls for icon size and padding.
- Reset defaults of **48 px icon size** and **4 px padding**, preserving a 56 px default outer chathead.
- Derive the outer chathead size from the chosen icon size and padding within safe touch-target and viewport bounds.
- Automatically choose a light or dark foreground for the close mark and other launcher foreground elements so contrast and focus visibility remain accessible on the selected background.

Persist branding in database-backed settings that work in local SQLite and deployed Postgres environments; do not depend on writing uploaded files into the deployed filesystem. Public widget surfaces may read only the safe branding values/assets they need. Saved changes take effect for newly loaded dashboard/widget pages without a redeploy, while a failed fetch or invalid stored value falls back to the bundled defaults.
