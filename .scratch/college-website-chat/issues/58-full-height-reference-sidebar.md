## Lifecycle decisions

- Restoring an Archived or Trashed answer returns it to Draft. An editor must explicitly Publish it before visitors can see it again.
- Both Owner and Editor roles can permanently delete from Trash.
- Trash is automatically purged 30 days after the answer enters Trash, in addition to manual permanent deletion. This does not use the conversation transcript-retention setting.

Implementing the agreed lifecycle requires narrow data/store/API changes in both supported stores, with the existing published-only visitor query remaining the safety boundary.
