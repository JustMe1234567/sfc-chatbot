## Current behavior

The Settings destination uses a hand-drawn mark made from a center circle and eight separate straight spokes. At sidebar size it can read as a sun or loading symbol instead of a conventional settings cog.

## Desired behavior

Replace only the Settings navigation mark with a recognizable cog/gear outline containing a centered circular opening. Keep it visually consistent with the existing sidebar icon system: the same view box, rendered size, stroke color, stroke weight, line treatment, active state, hover state, focus state, and disabled/contrast behavior.

The shared Settings mark must appear consistently anywhere the existing navigation data renders it, including the collapsed desktop rail, expanded desktop navigation, individual hover label, and mobile navigation. Keep the destination, `Settings` label, role visibility, ordering, accessible name, and all navigation behavior unchanged.

Use the project's existing inline SVG/`Mark` pattern. Do not add an icon library or new dependency for this single icon change.
